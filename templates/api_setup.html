Leave blank for the provider's default. Providers retire old model names now and then; if marking says the model was not found, type a current one here.

The key is stored on the server, never shown in full again, and never sent to respondents' browsers. For open-text quiz questions, if the AI call ever fails, grading falls back to keyword matching so quizzes keep working.

Get a free key in 3 steps

  1. 1 Open aistudio.google.com/apikey and sign in with a Google account.
  2. 2 Click Create API key and copy it (it starts with AIza).
  3. 3 Paste it here, keep Auto-detect, and press Save key.

Other keys that work

  • Groq (gsk_): free key at console.groq.com/keys
  • OpenRouter (sk-or-): has free models. Type a model name that ends in :free in Advanced.
  • OpenAI (sk-) and Claude (sk-ant-) are paid.
  • Anything else that is OpenAI-compatible: choose Other and give its base URL.

Good to know

  • Free tiers have request limits and their terms change, so check the provider's current rules.
  • Some free tiers may use prompts to improve their products. Do not paste real students' private details.
  • Marking photos needs a model that can read images. Typed answers work with any model.
